# 알림 템플릿 v2 형식

v1 템플릿을 v2로 이관할 때 지켜야 할 규칙이다. 스키마 검사(`npm run lint:template <파일>`)가 이 규칙을 강제한다.

## 필수 필드

| 필드 | 형식 | 설명 |
|---|---|---|
| `version` | 숫자 `2` | 형식 버전 |
| `channel` | 문자열 | `push`, `email`, `sms` 중 하나 |
| `title` | 문자열 | 알림 제목 |
| `body` | 문자열 | 본문 |
| `variables` | 문자열 배열 | 본문과 제목에 사용한 변수 이름 목록 |
| `optOut` | 객체 | `text`와 `url` 두 필드를 가진다 |

## 변경 규칙

1. 자리표시자는 `{{변수명}}` 형식만 사용한다. v1의 `$변수명` 표기는 모두 변환한다.
2. v1의 `vars` 필드는 `variables`로 이름을 바꾸고, 실제로 사용한 변수만 남긴다.
3. `optOut`이 없으면 추가한다. `text`는 수신 거부 안내 문구, `url`은 `{{unsubscribe_url}}`로 둔다.
4. 문구의 의미는 바꾸지 않는다. 형식만 변환한다.
