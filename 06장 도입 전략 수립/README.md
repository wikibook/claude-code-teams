# 6장 실습 안내

6장 「도입 전략 수립」의 실습 폴더입니다. 저장소는 `paylog` 하나이며, 코드가 아니라
파일럿 운영에 쓰는 **문서 양식 2건**만 담고 있습니다. 6장은 도입 의사결정을 다루는 장이라
실행할 코드는 없고, 본문 예제와 문자 단위로 일치하는 양식 문서를 제공합니다.

<br>

## 6장에서 만든 파일 (본문 예제와 문자 단위 일치)

- `paylog/docs/파일럿 기준 문서의 양식.md`: 예제 6.1 (대상·기간, 성공 기준, 실패 기준)
- `paylog/docs/보안 검토 답변 문서의 양식.md`: 예제 6.2 (계약·데이터 범위·기술 통제)

<br>

## 실습 방법

1. 두 양식을 자신의 조직 값으로 채워 봅니다. 팀·저장소·기간, 성공·실패 기준의
   수치는 본문 6.1.2의 판정 기준 논의를 참고해 조정합니다.
2. 파일럿 기준 문서는 파일럿 시작 전에 확정하고, 종료 시점에 같은 문서로 판정합니다.
3. 보안 검토 답변 문서는 보안·법무 검토 요청이 왔을 때 근거 문서와 확인일을 채워
   회신하는 용도로 사용합니다(6.4의 사실 확인 절차와 함께 씁니다).

<br>

## 유의점

- 이 폴더의 paylog에는 코드가 없습니다. 코드 실습은 4장(시작 상태)과 5장(완주 스냅샷)의
  paylog 폴더에서 진행합니다.
- 양식의 날짜·수치는 본문 사례(paylog 팀 파일럿)의 값이므로, 실제 사용 시 조직의
  값으로 교체해야 합니다.
