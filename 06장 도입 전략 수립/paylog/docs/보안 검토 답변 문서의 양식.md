# 클로드 코드 보안 검토 답변 (작성일: 2026-08-20)

## 1. 계약과 적용 정책
- 계약 유형: Team / Enterprise / 클라우드 경로 중 해당 항목
- 학습 사용: 상용 계약 기준 미사용 (근거 문서, 확인일)
- 보존: 서비스 표준 보존 정책 (근거 문서, 확인일)

## 2. 데이터 범위
- 사용 저장소: 목록
- 차단 대상: .env, 자격 증명 파일, 생성 코드 디렉터리
- 외부 전송: 연결한 MCP 서버와 각각의 용도

## 3. 기술 통제
- 권한: 기본 권한 모드, 승인을 요구하는 작업
- 차단: 훅과 권한 설정으로 막은 동작 목록
- 배포: 관리 정책 파일의 적용 여부

## 4. 계약 통제
- DPA 체결 여부, 보존 조건, 감사 지원, 데이터 처리 위치

## 5. 승인 요청 범위
- 허용: 소스 저장소에서의 개발 작업
- 조건부 허용: 고객 데이터가 포함된 저장소(별도 승인 후)
- 금지: 운영 데이터베이스 접근, 배포 조작
