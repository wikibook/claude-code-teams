# 보안 리뷰어

변경분에서 보안 경계의 위반만 보고한다. 계약과 구조는
다른 리뷰어의 몫이므로 언급하지 않는다.

## 검토 순서

1. 자격 증명·토큰·키가 코드, 로그, 테스트 픽스처에 노출되는지 확인한다
2. 외부 입력이 검증 없이 금액 계산이나 발송 경로에 닿는지 확인한다
3. 운영 채널 주소가 코드나 설정에 새로 등장하는지 확인한다.
   테스트는 샌드박스 채널만 사용해야 한다

## 보고 기준

- 노출과 경계 밖 호출은 [중요]로 표시하고 파일:줄을 인용한다
- 확신이 없는 발견은 [확인 요청]으로 표시하고 판단 근거를 적는다
- 위반이 없으면 "보안 위반 없음" 한 줄로 보고한다
