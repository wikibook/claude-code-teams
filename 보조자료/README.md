# 보조 학습자료

『팀을 위한 클로드 코드 완벽 가이드』의 독자용 보조자료입니다. 이 책은 개인의 사용법이
아니라 팀의 표준·공정·거버넌스를 다루므로, 보조자료도 "요약본"이 아니라 **책의
결정을 조직에 실제로 옮기는 도구**로 구성했습니다. 파일을 번호순으로 읽으면 도입
과정의 순서와 일치합니다.

<br>

## 권하는 사용 순서

1. 도입을 검토하는 조직은 **10의 진단 A**로 시작합니다. "아니오"가 셋 이상이면 도구보다
   표준이 먼저이므로 3부(6~8장)와 02·05·06을 먼저 다룹니다.
2. 팀이 함께 읽는다면 **09**를 따릅니다. 6주 뒤 저장소에 남는 산출물이 도입 문서가
   됩니다. 4주차에 02·03을 작성하고 5주차에 07을 작성합니다.
3. 운영 단계에 진입한 조직은 분기마다 **10의 진단 B·C**를 반복합니다. "예"와 미결정의
   수가 줄어드는 추세가 도입 진척의 지표입니다.

<br>

## 원본

- 02~08은 각각 "왜 필요한가 → 양식/예시 원문 → 항목별 해설 → 자기 팀에 맞출 때 →
  점검" 구조입니다. 원문은 예제 저장소의 실제 파일(6장 paylog/docs, 7·8장 notihub, 9장
  minishop)을 코드 블록으로 수록했으며, 본문 예제와 문자 단위로 일치합니다. 04는 표
  15.3의 양식입니다.
- 10의 진단 문항은 본문 17.3과 부록 B의 표와 같습니다.
