# 발송 경로 리뷰

## 리뷰 순서

1. 재시도 로직이 specs/delivery-contract.md의 재시도 상한과
   간격 규칙을 지키는지 확인한다
2. 중복 제거 키의 구성이 바뀌는 변경은 위험으로 표시하고,
   계약 문서의 갱신이 동반되었는지 확인한다
3. 채널 어댑터 호출이 dispatch/의 파이프라인을 경유하는지 확인한다.
   어댑터 직접 호출이 발견되면 위반으로 보고한다
4. 테스트가 실패 경로(타임아웃, 부분 실패, 재시도 소진)를
   포함하는지 확인한다

## 판단 기준

- 발송 규칙의 원본은 specs/delivery-contract.md다. 문서와 구현이
  다르면 구현이 아니라 문서를 기준으로 보고한다
- 세부 관례는 services/api/CLAUDE.md를 따른다
