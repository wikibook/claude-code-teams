# 커밋 절차

1. git status와 git diff로 변경 파일을 확인하고 논리 단위로 묶는다.
   서로 다른 관심사가 섞여 있으면 커밋을 나눈다
2. 커밋 메시지는 한국어로 쓴다. 첫 줄은 "영역: 변경 요약" 형식이다
   (예: api: 재시도 간격 상한 추가)
3. 저장소에 커밋 전 검사가 있으면 먼저 통과 여부를 확인하고,
   실패하면 커밋하지 않고 보고한다
