# 3장 실습 안내

3장 「핵심 개발 워크플로」의 실습 폴더입니다. 예제 프로젝트는 moneylog 하나이며,
브라우저에서 지출을 등록하고 월별 합계를 확인하는 작은 가계부 웹 애플리케이션입니다
(파이썬 표준 라이브러리만 사용). 인수인계 문서 없이 넘겨받은 저장소라는 설정으로,
탐색 → 지시 → 계획 검토 → 워크플로 → 명세의 3장 전체를 이 저장소 위에서 진행합니다.

<br>

## 준비

1. `moneylog` 디렉터리로 이동해 클로드 코드를 실행합니다. 파이썬 3.10 이상과 pytest가 필요합니다.

   ```
   cd moneylog
   python -m pytest tests/   # 시작 상태 확인 (전체 통과)
   python run.py             # 서버 실행 후 http://localhost:8000
   claude
   ```

<br>

## 본문에서 사용하는 곳

- 3.1.1 탐색: 개요 질문, @ 참조로 summary.py 집계 로직 분석
- 3.1.2 지시: 환불 배지 표시(나쁜 지시 vs 좋은 지시 비교)
- 3.1.3 플랜 모드: 삭제 기능 계획·승인, soft delete 전환 계획 수정
- 3.2.1 테스트 워크플로: 환불 합산 버그(예제 3.1) 디버깅, 월 필터 중복 리팩터링, 예산 TDD
- 3.2.2 화면 워크플로: 시안 기반 요약 카드 구현과 스크린샷 왕복
- 3.3 명세: specs/budget-alert.md 초안을 인터뷰로 구체화(예제 3.2)하고 새 세션에서 구현

<br>

## 유의점

- 시작 상태에는 **의도된 버그**가 있습니다. `moneylog/services/summary.py`가 `abs()`로
  합산해 환불이 지출로 더해집니다(예제 3.1). 3.2.1의 디버깅 재료이므로 미리 고치지 마세요.
- `specs/budget-alert.md`는 **의도적으로 미완성인 초안**입니다. 3.3.1의 인터뷰 실습이
  이 초안을 구체화합니다. 본문 예제 3.2는 인터뷰를 거쳐 다시 쓰인 결과물이므로
  저장소의 초안과 내용이 다릅니다.
- 실습이 코드를 수정하므로, 처음 상태로 되돌리려면 `git checkout -- .`을 사용하세요.
  본문 세션이 만드는 결과물(배지, 삭제 기능, 예산 경고)은 독자가 재현하는 것으로
  저장소에는 포함되어 있지 않습니다.
