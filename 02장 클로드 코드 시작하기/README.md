# 2장 실습 안내

2장 「클로드 코드 시작하기」의 실습 폴더입니다. 예제 프로젝트는 hello-todo 하나이며,
브라우저에서 동작하는 작은 할 일 목록 웹 애플리케이션입니다. 첫 세션에서 에이전트와
작업을 주고받는 기본 사이클(대화 → 파일 수정 → 승인 → 실행 확인)을 익히는 재료로 사용합니다.

<br>

## 준비

1. 이 폴더의 `hello-todo` 디렉터리로 이동해 클로드 코드를 실행합니다(예제 2.5).

   ```
   cd hello-todo
   claude
   ```

2. 테스트 실행에는 Node.js 22 이상이 필요합니다. 브라우저 실행은 `index.html`을 여는 것으로 충분합니다.

<br>

## 본문에서 사용하는 곳

- 2.3.1 기본 흐름: 프로젝트 탐색 질문, 완료 항목 숨기기 버튼 추가, `!` 셸 모드로 `node --test` 실행
- 2.3.2 중단과 되돌리기: 모호한 지시("더 좋게 개선해줘")로 시작한 작업을 Esc로 중단하고 /rewind로 복원
- 2.3.3 이미지 입력: 스크린샷으로 버튼 위치 수정, 시안 기반 스타일 변경, 시안·구현 비교
  (시안 이미지는 이 폴더의 `hello-todo-design-mockup.png`를 사용합니다)

<br>

## 확인 방법

- 테스트: `node --test` → 3개 통과(추가, 완료 처리, 숨기기)
- 화면: `index.html`을 브라우저로 열어 추가 → 완료 체크 → 숨기기 토글 확인

<br>

## 유의점

- 실습을 진행하면 `index.html`이 수정됩니다. 처음 상태로 되돌리려면 `git checkout -- .`
  또는 클로드 코드의 /rewind를 사용하세요.
- 이 폴더의 hello-todo는 실습 시작 상태입니다. 본문 세션이 만드는 변경(숨기기 버튼 등)은
  독자가 직접 재현하는 결과물이므로 저장소에는 포함되어 있지 않습니다.
